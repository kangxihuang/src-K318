# (附文档)Springboot3+Vue3+MySQL 在线阅读系统

**技术栈**：Springboot3、Vue3、MySQL

### 系统简介

墨韵书阁在线阅读系统是一套基于 SpringBoot3 + Vue3 的前后端分离架构的完整源码项目。系统包含前台门户、作者创作中心与后台管理三大端，提供书籍浏览、章节阅读、阅读进度追踪、作品发布与管理、用户与内容审核等完整功能链路。系统内置 JWT 身份认证、MD5 密码加密、MyBatis-Plus 分页查询等机制，可直接作为商城类阅读平台的业务基础。
 
### 核心功能
 
### 普通用户端

 
- 用户注册与登录：通过用户名、昵称、密码完成账号注册，注册后自动分配 USER 角色；登录校验用户名、密码及账号状态（禁用账号无法登录），登录成功签发 JWT Token 并返回用户基本信息。 
- 书籍列表浏览：支持分页加载书籍列表，可按书名关键词模糊搜索、按分类 ID 精确筛选，仅展示审核通过（status=1）的书籍，列表项展示封面、书名、作者昵称、分类名称、章节数、字数、阅读量及连载状态。 
- 书籍详情查看：点击书籍进入详情页，展示书籍完整信息（封面、描述、作者、分类、字数、阅读量、是否完结），同时自动将书籍阅读量 +1，并获取该书全部章节列表（按章节排序号升序，仅含章节标题、字数、排序号）。 
- 在线章节阅读：通过阅读器页面按章节 ID 加载章节正文内容，支持章节标题与正文展示，可切换上一章/下一章进行连续阅读。 
- 阅读进度自动保存：阅读时自动向服务器提交当前书籍 ID、章节 ID 与阅读进度百分比，系统按用户+书籍维度保存或更新最近阅读记录，记录最后阅读时间。 
- 阅读历史列表：展示当前用户全部阅读记录，按最近阅读时间倒序排列，每条记录显示书籍封面、书名、作者昵称、最近阅读章节标题，支持删除单条历史记录。 
- 个人资料管理：查看并修改个人昵称、头像、邮箱、手机号等基本信息（用户名、角色、状态不可自行修改）。 
- 修改登录密码：输入原密码验证身份后，可设置新密码，密码经 MD5 加密后存储。 
- 首页推荐与热门书籍：首页展示按阅读量倒序的推荐书籍（默认 6 本）与热门书籍榜单（默认 10 本），均仅含审核通过书籍。 
- 分类浏览：前台展示全部分类列表，每个分类附带该分类下已审核书籍数量，点击分类可筛选对应书籍。 
- 站内公告查看：前台首页展示最新发布的 5 条启用状态公告，公告按发布时间倒序排列。
 
### 作者端

 
- 作品列表管理：作者查看自己发布的全部书籍，按创建时间倒序分页展示，列表含封面、书名、分类、字数、阅读量、审核状态与章节数。 
- 新建书籍：作者可创建新书，需填写书名、封面、描述、分类、是否完结等信息，新书默认审核状态为待审核（status=0），阅读量与字数初始为 0。 
- 编辑书籍：作者可修改自己名下书籍的标题、封面、描述、分类、完结状态等字段，但不可修改作者 ID 与审核状态。 
- 删除书籍：作者可删除自己名下的书籍，删除后该书及其章节数据一并移除。 
- 章节列表管理：查看指定书籍的全部章节，按排序号升序展示章节标题、字数与排序号。 
- 新增章节：作者可为自己的书籍添加新章节，填写章节标题与正文内容，系统自动计算正文字数并写入章节字数；若未指定排序号，则自动取当前最大排序号 +1；新增章节后自动累加更新书籍总字数。 
- 编辑章节：修改章节标题、正文内容或排序号，保存后重新计算该章节字数并同步更新书籍总字数。 
- 删除章节：删除指定章节后，自动重新计算并更新所属书籍的总字数。 
- 章节详情预览：按章节 ID 获取章节完整内容（含正文），供作者编辑前预览或回显。
 
### 管理员端

 
- 数据概览统计：管理员首页展示系统核心指标，包括用户总数、书籍总数、分类总数与公告总数。 
- 用户列表查询：分页展示全部用户，支持按用户名或昵称模糊搜索，列表含用户 ID、用户名、昵称、角色、状态、创建时间。 
- 新增用户：管理员可手动添加用户，需提供用户名、密码、昵称、角色、状态等信息，密码自动 MD5 加密。 
- 编辑用户：修改用户昵称、头像、邮箱、手机号、角色等字段；若填写新密码则更新密码，留空则保持原密码不变。 
- 删除用户：根据用户 ID 移除指定用户账号。 
- 启用/禁用用户：通过切换用户状态（1 启用 / 0 禁用）控制账号登录权限，被禁用用户无法登录系统。 
- 修改用户角色：直接调整用户角色，支持在 USER、AUTHOR、ADMIN 三种角色间切换。 
- 书籍列表管理：分页展示全部书籍（含待审核、已通过、已拒绝所有状态），支持按书名关键词、分类 ID、审核状态组合筛选。 
- 书籍审核操作：对待审核书籍执行通过（status=1）或拒绝（status=2）操作，审核结果即时生效。 
- 删除违规书籍：管理员可强制删除任意书籍，删除后该书及章节数据一并清除。 
- 分类列表管理：查看全部分类，每个分类附带该分类下已审核书籍数量，分类按排序号升序排列。 
- 新增分类：填写分类名称、描述、排序号即可创建新分类。 
- 编辑分类：修改分类名称、描述、排序号等字段。 
- 删除分类：移除指定分类，删除后该分类下书籍将失去分类归属。 
- 公告列表管理：分页展示全部公告，含标题、封面、内容摘要、显示状态、发布时间。 
- 发布公告：填写公告标题、封面图片、正文内容，并设置显示状态（1 显示 / 0 隐藏），系统自动记录当前管理员 ID 为发布人。 
- 编辑公告：修改公告标题、封面、内容或显示状态。 
- 删除公告：移除指定公告，删除后前台不再展示。
 
### 技术栈

 后端框架Spring Boot 3.x ORM 框架MyBatis-Plus（含分页插件） 权限认证JWT（jjwt）+ 自定义登录拦截器 前端框架Vue 3（Composition API + script setup） 状态管理Pinia（用户登录状态存储） 路由管理Vue Router 4（含路由守卫鉴权） UI 组件库Element Plus 构建工具Vite 数据库MySQL 8.x（数据库名 online_reading） 文件上传本地磁盘存储（UUID 重命名 + 静态资源映射）
